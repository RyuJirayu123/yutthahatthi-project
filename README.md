# ยุทธหัตถี · Elephant Duel (Godot 4)

เกมต่อสู้ช้างศึก 2D พอร์ตมาจากเวอร์ชัน HTML ใน `Game Development Planning/` (ไฟล์ต้นฉบับยังเก็บไว้ และมี `.gdignore` กันไม่ให้ Godot import)

เปิดด้วย Godot 4.7: Import → เลือก `project.godot` → กด F5

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `scenes/main.tscn` | ซีนหลัก — ตั้งรายชื่อช้าง (`roster`), บอส, AI แต่ละด่าน และกติกาได้ใน Inspector ของโหนด `Main` |
| `scripts/main.gd` | flow ของเกม: เปลี่ยนหน้าจอ, ด่าน, คะแนน, บันทึกสถิติ (`user://save.cfg`) |
| `scripts/duel.gd` | จำลองแมตช์: ยก, เวลา, ตรวจการโจมตี, อนุภาค |
| `scripts/fighter.gd` | ช้างหนึ่งเชือก: เดิน กระโดด ป้องกัน โจมตี และ AI |
| `scripts/arena.gd` | วาดช้าง อนุภาค และ HUD แบบเกมต่อสู้ (รูปหน้าช้างในกรอบทอง, หลอดเลือด, นาฬิกา) ด้วย `_draw()` |
| `scripts/backdrop.gd` | ฉากหลังหลายชั้น: ฟ้า ภูเขา ปรางค์ ต้นตาล ต้นไม้ ทุ่งนา ลานดิน — 3 ช่วงเวลา (`day` / `sunset` / `dusk`) อาร์เคดด่าน 1→3 ใช้ตามลำดับ ชั้นที่หนักจะ "อบ" เป็นรูปครั้งเดียวตอนเริ่มด่าน |
| `scripts/draw_kit.gd` | ตัวช่วยวาดเร็ว: mesh ที่สร้างไว้ล่วงหน้า + primitive แทน `draw_polygon`/`draw_circle` ที่ช้า (ใช้ตอนวาดช้างและ HUD ทุกเฟรม) |
| `scripts/elephant_rig.gd` | วาดช้าง + ควาญ (แสงเงา, ผ้าคลุมลายทอง, เครื่องประดับ) และ animation: ท่าทางเลือกจากสถานะ, spring ทำให้ทุกข้อต่อเคลื่อนนุ่ม, ขาใช้ IK |
| `scripts/ui.gd` | เมนูทุกหน้า รวมหน้าเลือกช้าง สร้างด้วยโค้ด |
| `scripts/elephant_preview.gd` | ช้างขยับได้ในกล่อง UI (การ์ดหน้าเลือกช้าง) |
| `scripts/sfx.gd` | Autoload `Sfx` — สังเคราะห์เสียงตอนเริ่มเกม ไม่ต้องใช้ไฟล์เสียง |
| `scripts/game_data.gd` | ชุดสีทั้งเกม (แดงชาด ทอง ครีม), ค่าท่าโจมตี, ฟอนต์ |
| `data/elephants/*.tres` | ข้อมูลช้างแต่ละเชือก (`ElephantDef`): สีผิว (`body`/`dark`), สีผ้าคลุมประจำตัว (`cloth`), สีทอง (`trim`), ธง, เครื่องทรงหลวง (`royal` = ฉัตร+มงกุฎ), ค่าพลัง, คำโปรย |
| `data/ai/*.tres` | ความเก่งของ AI (`AIProfile`) — easy / normal / hard ใช้ตามด่าน |

## ต่อยอด

- **เพิ่มช้าง:** duplicate ไฟล์ `.tres` ใน `data/elephants` แก้ชื่อ สี ค่าพลัง (`hp`, `power`, `speed`, `rider_skill`, `steady`, `charge`) แล้วลากใส่ `Roster` ของโหนด `Main` — จะขึ้นในหน้าเลือกช้างอัตโนมัติ
- **ปรับความยาก:** แก้ไฟล์ใน `data/ai/` (ด่าน 1 = easy, 2 = normal, 3 = hard)
- **ปรับท่าทาง/animation:** แก้ `_targets()` ใน `elephant_rig.gd` (ท่างวงอยู่ในตาราง `TRUNK`, ความเด้งของแต่ละข้อต่ออยู่ใน `SPRING`)
- **ปรับท่าโจมตี:** แก้ `_build_moves()` ใน `game_data.gd` — แต่ละท่ามีหลายจังหวะตีได้ (`_hit`: เฟรมเริ่ม/จบ, ระยะ, ดาเมจ, แรงกระเด็น, ป้องกันไม่ได้, ดึง, ทำให้เสียหลัก) และค่าท่า (พุ่ง, เกราะ, เหตุการณ์พิเศษ)
- **เปลี่ยนท่าของช้าง:** ช่อง `signature` / `ultimate` ในไฟล์ `.tres` ของช้าง (เลือกจาก dropdown ใน Inspector)
- **เปลี่ยนสีช้าง:** แก้ `cloth` (สีประจำทีม ใช้ทั้งผ้าคลุม เสื้อควาญ และกรอบรูปใน HUD) กับ `body`/`dark` (สีผิว) ในไฟล์ `.tres`
- **ปรับฉาก:** สีของแต่ละช่วงเวลาอยู่ในตาราง `PALETTES` ของ `backdrop.gd` ตำแหน่งต้นไม้/วัดอยู่ใน `_build()` — เพิ่มช่วงเวลาใหม่ได้โดยเพิ่ม palette แล้วใส่ชื่อใน `SCENES`
- **เปลี่ยนปุ่ม:** Project → Project Settings → Input Map (`p1_*`, `p2_*`, `pause`, `mute`, `fullscreen`)

## ช้างให้เลือก

| ช้าง | สไตล์ | ท่าประจำตัว (G) | อัลติ (H, พลังเต็ม) |
| --- | --- | --- | --- |
| พลายแสง | สมดุลรอบด้าน | แทงงา — แทงหนัก กระเด็นไกล | พุ่งชนสามจังหวะ — พุ่งชน แล้วต่องาและของ้าว |
| พลายเมฆ | ควาญฝีมือดี | งาเกี่ยว — ดึงเข้ามาใกล้ ต่อของ้าวได้ | ของ้าวพายุ — หมุนของ้าวฟัน 3 ครั้ง ตีหลอดทรงตัวหนัก |
| พลายดิน | ว่องไว | พุ่งแทง — พุ่งเข้าเร็ว ระยะไกล | ฝีเท้าสายฟ้า — พุ่งทะลุไปข้างหลังแล้วแทง ป้องกันไม่ได้ |
| พลายเหล็ก | อึด ช้า | หัวโขก — ตอนง้างโดนตีไม่สะดุ้ง | กระทืบธรณี — คลื่นวิ่งไปตามพื้น ต้องกระโดดหลบ |
| พลายเผือก | ชาร์จไว | งวงหวด — ระยะยาว ได้หลอดพลังเยอะ | บารมีช้างเผือก — ฟื้นเลือด/ทรงตัว แรงขึ้น ×1.25 นาน 6 วิ |
| พญาคชสาร | บอส (ปลดล็อกเมื่อชนะอาร์เคด) | งาคู่ — แทงสองจังหวะ | คชสารคำราม — ควาญฝ่ายตรงข้ามเสียหลักทันที |

ค่า "ความมั่นคง" ในหน้าเลือกช้าง = ควาญเสียหลักยากแค่ไหน (หลอด "ทรงตัว" ระหว่างสู้ลดช้าลง)

อาร์เคด: เลือกช้าง แล้วสู้ 2 ด่านสุ่ม + บอส · ประลอง: เลือกช้างเหมือนกันได้ (ผู้เล่น 2 ได้สีสลับ)
หน้าเลือกช้าง: P1 A/D เลือก · F/Enter ยืนยัน · G ยกเลิก — P2 ←/→ · `,` ยืนยัน · `.` ยกเลิก — คลิกการ์ดก็ได้ · ESC กลับ

## ปุ่ม

P1: A/D เดิน · W กระโดด · S ป้องกัน · F งวง · G งา · H ชาร์จ · J ควาญฟันของ้าว
P2: ←/→ · ↑ · ↓ · `,` `.` `/` `;` (หรือ Numpad 1 2 3 4)
จอย: X งวง · Y งา · B ชาร์จ · RB ของ้าว · A กระโดด · LB ป้องกัน

ควาญ: ของ้าวฟันข้ามการป้องกันแต่ช้า (งวงฟาดขัดได้) · ควาญกับช้างโจมตีแยกกัน กดพร้อมท่าช้างเป็นคอมโบได้ (ใช้ไม่ได้ตอนป้องกัน/โดนตี/เสียหลัก) · โดนตีหลอด "ทรงตัว" จะลด หมดแล้วควาญเสียหลัก ~2 วินาที — ฟันของ้าวซ้ำตอนนั้น = **ฟันปิดฉาก** (ดาเมจหนัก)
ESC/P หยุด · M เสียง · F11 เต็มจอ · จอยตัวที่ 1 = P1, ตัวที่ 2 = P2

ฟอนต์ Archivo และ IBM Plex Sans Thai ใช้สัญญาอนุญาต SIL OFL (ดู `assets/fonts/*-OFL.txt`)

## Export / publish

- ตั้งค่าไว้ใน `export_presets.cfg` แล้ว 2 แบบ: **Web** → `build/web/index.html` และ **Windows** → `build/windows/ElephantDuel.exe`
- Export: เปิด Godot → Project → Export → Export Project หรือผ่าน command line:
  `Godot_console.exe --headless --path . --export-release "Web" build/web/index.html`
- itch.io: zip ไฟล์ในโฟลเดอร์ `build/web` (ให้ `index.html` อยู่ที่ root ของ zip) → อัปโหลด เลือก "This file will be played in the browser" → ตั้งขนาด 960×540 และเปิด Fullscreen button
- เวอร์ชันเว็บเป็นแบบ single-thread จึงไม่ต้องเปิด SharedArrayBuffer
- ฟอนต์ใช้สัญญาอนุญาต OFL ต้องแนบไฟล์ `*-OFL.txt` ไปด้วยเวลาแจกเกม
- **หน้าโหลดบนเว็บ:** อยู่ที่ `web/shell_src.html` แก้ไฟล์นี้แล้วรัน `python web/build_shell.py` เพื่อสร้าง `web/shell.html` (preset Web ใช้ไฟล์นี้ และฝังรูปช้างไว้ในไฟล์เดียว) ก่อน export ใหม่
- **ความละเอียด:** เกมวาดแบบเวกเตอร์บนพิกัด 960×540 แล้วขยายตามจอ จึงคมชัดทุกความละเอียด บนคอมเปิดเต็มจอ (F11 สลับเป็นหน้าต่าง 1920×1080) บนเว็บขยายเต็มหน้าต่างเบราว์เซอร์
- **ทำไฟล์ปล่อยเกมทีเดียวครบ:** `powershell -File web\build_release.ps1` จะสร้างหน้าโหลด, export ทั้งสองแบบ และได้ `build/ElephantDuel-web.zip` กับ `build/ElephantDuel-windows.zip`

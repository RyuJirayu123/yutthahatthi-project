# ยุทธหัตถี · Elephant Duel (Godot 4)

เกมต่อสู้ช้างศึก 2D พอร์ตมาจากเวอร์ชัน HTML ใน `Game Development Planning/` และหน้าตาช้างมาจากดีไซน์ใน `ออกแบบช้างเกม Godot/` (สองโฟลเดอร์นี้มี `.gdignore` กันไม่ให้ Godot import)

เปิดด้วย Godot 4.7: Import → เลือก `project.godot` → กด F5

## ต่อยอด

- **เพิ่มช้าง:** duplicate ไฟล์ `.tres` ใน `data/elephants` แก้ชื่อ สี ค่าพลัง (`hp`, `power`, `speed`, `rider_skill`, `steady`, `charge`) แล้วลากใส่ `Roster` ของโหนด `Main` — จะขึ้นในหน้าเลือกช้างอัตโนมัติ
- **ปรับความยาก:** แก้ไฟล์ใน `data/ai/` (ด่าน 1 = easy, 2 = normal, 3 = hard)
- **ปรับท่าทาง/animation:** แก้ `_targets()` ใน `elephant_rig.gd` (ท่างวงอยู่ในตาราง `TRUNK`, ความเด้งของแต่ละข้อต่ออยู่ใน `SPRING`)
- **ปรับท่าโจมตี:** แก้ `_build_moves()` ใน `game_data.gd` — แต่ละท่ามีหลายจังหวะตีได้ (`_hit`: เฟรมเริ่ม/จบ, ระยะ, ดาเมจ, แรงกระเด็น, ป้องกันไม่ได้, ดึง, ทำให้เสียหลัก) และค่าท่า (พุ่ง, เกราะ, เหตุการณ์พิเศษ)
- **เปลี่ยนท่าของช้าง:** ช่อง `signature` / `ultimate` ในไฟล์ `.tres` ของช้าง (เลือกจาก dropdown ใน Inspector)
- **เปลี่ยนสีช้าง:** แก้ `cloth` (สีประจำทีม ใช้ทั้งผ้าคลุม ผ้าโพกหัว และกรอบรูปใน HUD) กับ `body`/`dark` (สีผิว) ในไฟล์ `.tres`
- **ปรับฉาก:** สีของแต่ละช่วงเวลาอยู่ในตาราง `PALETTES` ของ `backdrop.gd` ตำแหน่งต้นไม้/วัดอยู่ใน `_build()` — เพิ่มช่วงเวลาใหม่ได้โดยเพิ่ม palette แล้วใส่ชื่อใน `SCENES`
- **เปลี่ยนปุ่ม:** Project → Project Settings → Input Map (`p1_*`, `p2_*`, `pause`, `mute`, `fullscreen`)

## ช้างให้เลือก

| ช้าง | สไตล์ | ท่าประจำตัว (G) | อัลติ (H, พลังเต็ม) |
| --- | --- | --- | --- |
| พลายแสง | สมดุลรอบด้าน | แทงงา — แทงหนัก กระเด็นไกล | พุ่งชนสามจังหวะ — พุ่งชน ต่องา แล้วโขกปิดท้าย |
| พลายเมฆ | ตีเสียหลักเก่ง | งาเกี่ยว — ดึงเข้ามาใกล้ ต่อท่าได้ | งวงพายุ — สะบัดงวงหมุนฟาด 3 ครั้ง ตีหลอดทรงตัวหนัก |
| พลายดิน | ว่องไว | พุ่งแทง — พุ่งเข้าเร็ว ระยะไกล | ฝีเท้าสายฟ้า — พุ่งทะลุไปข้างหลังแล้วแทง ป้องกันไม่ได้ |
| พลายเหล็ก | อึด ช้า | หัวโขก — ตอนง้างโดนตีไม่สะดุ้ง | กระทืบธรณี — คลื่นวิ่งไปตามพื้น ต้องกระโดดหลบ |
| พลายเผือก | ชาร์จไว | งวงหวด — ระยะยาว ได้หลอดพลังเยอะ | บารมีช้างเผือก — ฟื้นเลือด/ทรงตัว แรงขึ้น ×1.25 นาน 6 วิ |
| พญาคชสาร | บอส (ปลดล็อกเมื่อชนะอาร์เคด) | งาคู่ — แทงสองจังหวะ | คชสารคำราม — อีกฝ่ายเสียหลักทันที |

ค่า "ความมั่นคง" ในหน้าเลือกช้าง = ช้างเสียหลักยากแค่ไหน (หลอด "ทรงตัว" ระหว่างสู้ลดช้าลง) · ค่า "ทำลายสมดุล" = ตีแล้วหลอดทรงตัวอีกฝ่ายลดเร็วแค่ไหน

อาร์เคด: เลือกช้าง แล้วสู้ 2 ด่านสุ่ม + บอส · ประลอง: เลือกช้างเหมือนกันได้ (ผู้เล่น 2 ได้สีสลับ)
หน้าเลือกช้าง: P1 A/D เลือก · F/Enter ยืนยัน · G ยกเลิก — P2 ←/→ · `,` ยืนยัน · `.` ยกเลิก — คลิกการ์ดก็ได้ · ESC กลับ

## ปุ่ม

P1: A/D เดิน · W กระโดด · S ย่อ · F งวงฟาด (ระยะสั้น) · R แทงงา (ระยะกลาง) · G ท่าประจำตัว · H อัลติ
P2: ←/→ · ↑ · ↓ · `,` `L` `.` `/` (หรือ Numpad 1 5 2 3)
จอย: X งวง · LB แทงงา · Y ท่าประจำตัว · B อัลติ · A กระโดด

ป้องกัน: **กด ↓ (S) ค้าง = ย่อกัน กันได้ทุกท่า** ยกเว้นอัลติบางท่า

ทรงตัว: โดนตีหลอด "ทรงตัว" จะลด หมดแล้วช้างเสียหลักเซอยู่กับที่ ~1 วินาที — กด G ท่าประจำตัวใส่ตอนนั้น = **กระแทกปิดฉาก** (ดาเมจหนัก)
ESC/P หยุด · M เสียง · F11 เต็มจอ · จอยตัวที่ 1 = P1, ตัวที่ 2 = P2

**ฝึกซ้อม · สอนเล่น** (เมนูหลัก 03): เลือกช้างแล้วเรียนทีละบท 14 บท ตั้งแต่พุ่งตัว ย่อป้องกัน ระยะสั้น/กลาง คอมโบ ท่าพิเศษ EX ปัดสวน กระแทกปิดฉาก จนถึงอัลติ — เกมเช็กว่าทำได้จริงแล้วขึ้น "ผ่าน!" ไปบทถัดไปเอง เรียนครบแล้วเป็นฝึกอิสระ (หุ่นไม่ตาย เลือดเต็มเองเมื่อพัก มีดาเมจคอมโบและปุ่มที่กดโชว์) กด ESC เพื่อข้ามบท เปลี่ยนท่าหุ่น (ยืน/ย่อ/ป้องกันทุกท่า/กระโดด/สู้กลับ) หรือเปิด-ปิดพลังเต็มตลอด

คอมโบ (ดูในเกมได้ที่ วิธีเล่น → ท่าคอมโบ):
- **F F F** คอมโบงวง 3 จังหวะ (ตวัดงวง → ทุบงวงให้ลอย) กดต่อได้เฉพาะตอนท่าก่อนหน้าตีโดน (ถ้าโดนกัน ชุดจะจบ อีกฝ่ายได้ตาตีสวน) · ท่าธรรมดาโดนกันไม่มีดาเมจขูด
- **ยกเลิกท่า:** ท่างวงโดนแล้วกด G = ตัดเข้าท่าประจำตัว · ท่างวงหรือท่าประจำตัวโดนแล้วกด H = ตัดเข้าอัลติ
- **กระโดด + F** ทิ้งตัวแทงงา · **แตะทิศ 2 ครั้ง** พุ่งตัว/ถอยหลบ · **ป้องกันโดนตีแล้วกด G** ปัดสวน (ใช้พลัง 25)
- **ตีลอยฟ้า:** ช้างที่โดนตีลอยจะลอยจนลงพื้น ตีซ้ำได้ 3 ครั้ง · ฮิตที่ 3 ขึ้นไปดาเมจลดทีละ 10% (ต่ำสุด 45%) และหลังฮิตที่ 4 เวลามึนลดลง คอมโบจึงจบเองราว 9–10 ฮิต
- ค่าต่างๆ อยู่ใน `scripts/game_data.gd` (ท่า `light2` `light3` `dive` `counter` และหมวด Combos) CPU ใช้คอมโบตามค่า `combo` ใน `data/ai/*.tres`

ระบบแบบ Street Fighter (→ = ทิศที่หันหน้าไป):
- **↓↘→ + F งวงพ่นน้ำ** ลูกน้ำวิ่งไปตามพื้น (ทีละลูก) กระโดดข้ามหรือป้องกันได้ · **→↓↘ + F งวงเสย** ตอนเริ่มท่าไม่โดนอะไร สวนคนกระโดด แต่พลาดแล้วโดนสวนหนัก — ทั้งสองท่าใช้ต่อจากท่างวงได้ และตัดเข้าอัลติได้
- **G + H พร้อมกัน = ท่า EX** ใช้พลัง 50 ท่าประจำตัวแรงขึ้น ×1.4 และไม่สะดุ้งตอนง้าง
- **สวนจังหวะ (Counter Hit)** ตีโดนตอนอีกฝ่ายกำลังออกท่า ดาเมจ ×1.2 และมึนนานขึ้น จนต่อท่าที่ปกติต่อไม่ทันได้
- **อัลติ** เวลาหยุด 0.85 วิ ฉากมืดลง กล้องซูมเข้าหาช้าง มีแถบชื่อท่าเลื่อนเข้ามา แล้วกล้องตามท่าแบบใกล้ขึ้นจนท่าจบ (`_update_camera` / `_draw_cut_in` ใน `scripts/arena.gd`)
- ค่าอยู่ในหมวด "Street-fighter style extras" ของ `scripts/game_data.gd`

ฟอนต์ Archivo และ IBM Plex Sans Thai ใช้สัญญาอนุญาต SIL OFL (ดู `assets/fonts/*-OFL.txt`)

## เล่นออนไลน์

ทั้งสองคนเปิดเกม (เว็บหรือ Windows ก็ได้) → **เล่นออนไลน์** → กด **สุ่มหาคู่** พร้อมกัน หรือคนหนึ่ง **สร้างห้อง** แล้วส่งรหัส 4 ตัวให้อีกคนกด **เข้าห้อง** → แต่ละคนเลือกช้างของตัวเอง (ใช้ปุ่มของผู้เล่น 1) → สู้ · จบแล้วกดแมตช์ใหม่ได้

ต้องมีเซิร์ฟเวอร์กลาง 1 ตัว (ฟรี) ทำครั้งเดียว:
1. push โปรเจกต์ขึ้น GitHub (มีโฟลเดอร์ `server/` และไฟล์ `render.yaml` แล้ว)
2. ไปที่ https://render.com สมัครด้วยบัญชี GitHub → **New** → **Blueprint** → เลือก repo `yutthahatthi-project` → **Apply** (ใช้แพ็กเกจ Free, ภูมิภาค Singapore)
3. รอสร้างเสร็จ จะได้ที่อยู่แบบ `https://elephant-duel-relay-xxxx.onrender.com` เปิดดูแล้วต้องขึ้น `elephant duel relay ok`
4. ใส่ที่อยู่ใน Godot: **Project → Project Settings → Online → Server Url** = `wss://elephant-duel-relay-xxxx.onrender.com` (เปลี่ยน https เป็น wss) แล้วกด `publish.bat` ใหม่
5. เซิร์ฟเวอร์ฟรีจะหลับถ้าไม่มีคนเล่น 15 นาที ครั้งแรกที่เข้าหน้าออนไลน์อาจรอ ~1 นาที (เกมปลุกให้เองตอนเปิดหน้าออนไลน์)

ทดสอบในเครื่องเดียวก็ได้: `cd server` · `npm install` · `node relay.js` แล้วเปิดเกม 2 หน้าต่าง (ถ้าไม่ได้ตั้ง Server Url เกมจะต่อ `ws://localhost:8080`) · `LAG_MS=60 node relay.js` จำลองเน็ตช้า

## ปล่อยเกม / อัปเดตเวอร์ชัน

**ดับเบิลคลิก `publish.bat`** แล้วเลือกเวอร์ชัน (Enter = สร้างเวอร์ชันเดิมซ้ำ, 1 = แก้บั๊ก, 2 = ของใหม่, 3 = อัปเดตใหญ่) ได้ไฟล์ครบใน `release/v<เวอร์ชัน>/`:

| ไฟล์ | เอาไปทำอะไร |
| --- | --- |
| `ElephantDuel-v<เวอร์ชัน>-web/` | **ดับเบิลคลิก `deploy.bat`** ส่งขึ้น GitHub Pages → เล่นได้ที่ https://ryujirayu123.github.io/yutthahatthi-project/ |
| `ElephantDuel-v<เวอร์ชัน>-web.zip` | itch.io → เลือก "This file will be played in the browser" ตั้งขนาด 960×540 เปิด Fullscreen button |
| `ElephantDuel-v<เวอร์ชัน>-windows.zip` | ให้คนโหลดไปเล่นบน Windows (มี `.exe` ไฟล์เดียว + ไฟล์สัญญาอนุญาตฟอนต์) |

- **เลขเวอร์ชันอยู่ที่เดียว:** `project.godot` → `config/version` (ใน Godot: Project Settings → Application → Config → Version) เกม หน้าโหลดบนเว็บ ข้อมูลไฟล์ `.exe` และชื่อไฟล์ทั้งหมดอ่านจากตรงนี้ `publish.bat` เปลี่ยนให้เองตอนเลือก 1–3
- ใช้แบบไม่ต้องตอบคำถาม: `publish.bat -Bump patch` / `minor` / `major` / `none` หรือ `publish.bat -Version 1.4.2`
- เวอร์ชันเก่ายังเก็บอยู่ใน `release/` ถ้าเวอร์ชันใหม่มีปัญหา ถอยกลับได้ด้วย `deploy.bat -Version 2.0.0`
- **GitHub Pages ครั้งแรก:** หลังรัน `deploy.bat` ครั้งแรก เข้า repo บน GitHub → **Settings → Pages** → Source: **Deploy from a branch** → Branch: **gh-pages** / **(root)** → Save (ทำครั้งเดียว) · `deploy.bat` เก็บไว้แค่เวอร์ชันล่าสุดใน branch `gh-pages` repo จะได้ไม่บวมขึ้นทีละ ~40 MB
- จดว่าแต่ละเวอร์ชันเปลี่ยนอะไรใน `CHANGELOG.md` แล้วตามด้วย `git commit -am "v1.1.1"` · `git tag v1.1.1` · `git push --follow-tags` (สคริปต์พิมพ์คำสั่งให้ตอนจบ)
- สคริปต์จริงอยู่ที่ `tools/publish.ps1` (แก้ path ของ Godot ได้ที่บรรทัด `$godot`)

### รายละเอียด export
- ตั้งค่าไว้ใน `export_presets.cfg` แล้ว 2 แบบ: **Web** และ **Windows** (exe ฝังข้อมูลเกมไว้ในไฟล์เดียว)
- เวอร์ชันเว็บเป็นแบบ single-thread จึงไม่ต้องเปิด SharedArrayBuffer
- ฟอนต์ใช้สัญญาอนุญาต OFL ต้องแนบไฟล์ `*-OFL.txt` ไปด้วยเวลาแจกเกม (สคริปต์ใส่ให้แล้ว)
- **หน้าโหลดบนเว็บ:** อยู่ที่ `web/shell_src.html` (`{{VERSION}}` จะถูกแทนด้วยเลขเวอร์ชัน) `publish.bat` สร้าง `web/shell.html` ให้เอง ถ้า export เองจาก Godot ให้รัน `python web/build_shell.py` ก่อน
- **ความละเอียด:** เกมวาดแบบเวกเตอร์บนพิกัด 960×540 แล้วขยายตามจอ จึงคมชัดทุกความละเอียด บนคอมเปิดเต็มจอ (F11 สลับเป็นหน้าต่าง 1920×1080) บนเว็บขยายเต็มหน้าต่างเบราว์เซอร์
